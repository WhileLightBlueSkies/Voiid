# Softer dark-theme preview

Shared iOS and Android dark tokens now use charcoal backgrounds (#14191C), card surfaces (#1B2226), and raised/received-bubble surfaces (#232C30). Primary text is off-white (#DDE3E4), secondary text #A2ADB0, and teal reading accents #78AAAD. Decorative purple, blue, green, and yellow accents are muted. Light-mode values and filled brand-button/bubble label pairs are unchanged.

Calculated minimum contrast across the three dark surfaces: primary text 10.98:1, secondary text 6.20:1, teal reading text 5.53:1. This is a shared-token preview, not a claim that every custom game board or media overlay has been visually audited. Review Chats, Moments, Communities, Games, settings, and sheets on a device before accepting the palette.
