# Game audio provenance

Required by [`docs/games/SOUND_DESIGN.md`](../../docs/games/SOUND_DESIGN.md) §8. Every shipped
sound needs a licence permitting **commercial use and redistribution inside a compiled
application**, and that has to be recorded *as files are added* — reconstructing provenance for
forty clips afterwards is how apps end up shipping audio they cannot defend.

---

## Status: all generated EXCEPT the six cricket crowd assets — see the warning below

Everything in this app is generated by code in this directory, with one exception: the crowd.
The synthesised bed was judged too fake to ship (2026-08-10) and was replaced with three real
recordings, which is the right call for a stadium — chalk and timber are impacts that model
well, thousands of real voices in a real room are not.

The trade is that those six files are the only assets here whose provenance is not "we made
it", and the section below is therefore the only thing standing between this repo and shipping
audio it cannot defend.

> ### ⚠️ THE CROWD ASSETS ARE NOT CLEARED FOR RELEASE
>
> The three sources came from **Zedge**, which is a ringtone/wallpaper distribution app, **not
> a stock-audio licensor**. Zedge hosts large amounts of user-uploaded content, its terms grant
> a licence for *personal use on your own device*, and it does not convey the right to
> redistribute a clip inside a commercial application. A file being free to download there says
> nothing about who owns it — a good deal of stadium audio on such sites is ripped from
> broadcast footage, which is owned by the broadcaster and is not licensable at all.
>
> **This is fine for development and for hearing the game as intended. It is not fine to ship.**
>
> Before release, replace all three with equivalents from a source that actually grants
> redistribution — Freesound (CC0 filter), Zapsplat, Soundsnap, Epidemic Sound, or a
> commissioned/self-made recording of any crowded venue. `crowd_import.py` takes a `--src`
> directory, so swapping them is a re-run and a rebuild, not a rewrite: every timing, slice
> point and gain in the pipeline is keyed to file names, not to these particular recordings.

Everything else remains first-party:

| Generator | Renders | Method |
|---|---|---|
| [`synth.py`](./synth.py) | UI ticks, all of Snake, RPS/cricket/TTT stingers | Oscillator primitives (sine/saw/square/noise), stdlib only |
| [`physical.py`](./physical.py) | `catch_shared`, chalk set, cricket impacts | Physical models — modal resonators, grain trains — over [`dsp.py`](./dsp.py) |
| [`crowd_import.py`](./crowd_import.py) | the six `crowd_*` assets | Conversion + mastering of the recordings above, not synthesis |

`synth.py` and `physical.py` are stdlib-only, deterministic, and seeded per sound name, so
regenerating one file cannot change another and every change is a reviewable binary diff.

**Copyright in the generated output belongs to Voiid**, as the output of first-party code. The
six `crowd_*` assets are NOT covered by that and carry whatever rights their unknown originator
holds — see the warning above.

## If third-party audio is ever added

Do not add a file without filling in a row here **in the same commit**. The table is the
licence record; a file present in `Resources/GameSounds/` and absent from this table is
unshippable.

The crowd table above is that record, and it is currently the open item: those six assets are
the reason this section exists rather than a hypothetical.

Acceptable licences: **CC0**, or a **commercial library licence** covering redistribution in a
compiled app. **CC-BY is not acceptable** as things stand — it requires attribution and the app
has nowhere to put it; adding a credits screen first would change that.

Also required for any sourced file, because the generators guarantee these and a download does
not: **mono**, **44.1 kHz**, no leading silence, no full-scale peaks. Run
`python3 tools/gamesounds/verify.py`, which asserts all of them across both platforms — a
stereo asset is a hard AVAudioEngine crash, not a quality problem.

## Regenerating

```sh
python3 tools/gamesounds/synth.py         # abstract palette
python3 tools/gamesounds/physical.py      # physical palette
python3 tools/gamesounds/crowd_import.py  # the crowd, from recordings in ~/Downloads
python3 tools/gamesounds/verify.py        # assert every property the spec requires
```

`crowd_import.py --src <dir>` is how the crowd gets replaced when properly licensed sources
arrive; it needs the three source files under their original names.

None of these is part of either app's build. Run them by hand when a sound changes and
commit the output, so the game builds stay free of a Python dependency.
